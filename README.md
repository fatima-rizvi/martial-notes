# Martial Notes

**Authors:** Fatima Rizvi and Michael Yanez

## About

Martial Notes is a MySQL database and Python application layer for organizing martial arts, moves and descriptions, events, and study sessions. This repository does not include the user-facing client. A randomized study mode is a future goal, not a feature in the current application.

## Requirements

- Python 3.10 or newer (required by the MySQL Connector/Python version used here)
- MySQL Server
- The Python package `mysql-connector-python`

## Create a Python virtual environment

From the repository root, create the environment:

```text
python -m venv venv
```

Activate it:

**macOS / Linux**

```text
source venv/bin/activate
```

**Windows PowerShell**

```text
venv\Scripts\Activate.ps1
```

Install the MySQL connector in the activated environment:

```text
python -m pip install mysql-connector-python
```

## Set up the database

Use a dedicated test database. The DDL script drops and recreates the project tables before loading sample data, so do not run it against a database containing data you need to keep.

1. Start MySQL Server and connect with MySQL Workbench or another MySQL client.
2. Choose a name for your test database, then create and select it. Replace `<your_database_name>` below with the name you chose:

   ```sql
   CREATE DATABASE IF NOT EXISTS your_database_name;
   USE <your_database_name>;
   ```

3. Run [`SQL/martial_notes_ddl.sql`](./SQL/martial_notes_ddl.sql) with your database selected. This creates the tables and inserts sample records.

## Configure and run the application

Open [`application/run_martial_notes_app.py`](./application/run_martial_notes_app.py) and update the MySQL connection values in `main()` to match your setup:

```python
host='localhost',
user='<your MySQL username>',
password='<your MySQL password>',
database='<your_database_name>'
```

Replace `<your_database_name>` with the database name you chose, and replace the username and password with your own MySQL credentials. Do not put real credentials in files you share or commit.

From the repository root, run:

```text
cd application
python run_martial_notes_app.py
```

The runner reads from all five tables, then demonstrates create, update, and delete operations and prints affected-row counts and table contents. A successful write generally prints a row count of `1`.

**The runner commits its changes to the configured database.** It leaves behind the Karate martial art, Front Kick move, Test Event, and study sessions it creates; repeated runs add more records. Use a disposable test database and re-run the DDL only when you are ready to drop and recreate its tables and sample data.

[`application/CLI_OUT.txt`](./application/CLI_OUT.txt) contains an example run. Output rows and generated IDs can vary depending on the database contents.
